## Prerequisites

Complete [Final project](../17-final-project/README.md), including its next-class preparation.

## Class plan

| Minutes | Activity |
|---|---|
| 00–05 | Retrieval practice and setup check |
| 05–15 | Review the request-to-database journey |
| 15–45 | Short demonstrations: run, request, persistence, and failure handling |
| 45–55 | Quiz, correction, and targeted feedback |
| 55–60 | Exit check and intermediate placement assignment |

## Lesson

### Core idea

Assessment focuses on explanation, reproducibility, and the ability to repair a small failure. The 20% milestone is breadth across this beginner curriculum, not production readiness.

### Practical artifact

Demonstrate the final project and identify concrete practice gaps.

## Exit check

- The lab artifact runs or is complete enough to explain.
- The learner can explain the core idea using a concrete request or booking example.
