# Lab: Structs, slices, maps, and business entities

**Starting point:** the referenced repository example or an empty personal exercise folder.
**Deliverable:** a saved exercise or commit, observed output, and a short explanation of one success and one failure. Use only synthetic data.

## Steps

1. Create a ClassSession struct and a slice containing three sessions.
2. Print ID, title, and remaining seats using range.
3. Find a session by ID, returning a clear error when absent.
4. Sketch Student, Course, ClassSession, and Booking with arrows and IDs.

## Acceptance checks

- [ ] Two sessions with the same title remain distinguishable.
- [ ] An absent ID is handled without crashing.
