## Lesson

### Core idea

Git records meaningful states so a mistake can be understood and reversed. Debugging starts with reproducing a failure and reading the first useful error.

### Practical artifact

Initialize a repository, commit a working booking program, and repair a deliberate bug.

## Exit check

- The lab artifact runs or is complete enough to explain.
- The learner can explain the core idea using a concrete request or booking example.
