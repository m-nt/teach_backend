1. Rebuild or rerun the class artifact from your saved work and capture the command/output.

4. Record one question or error for retrieval practice at the next meeting.

**Estimated time:** 2–4 hours total, including setup repair. Stop after 45 minutes on one blocking error and bring the exact message to class.

## Submission criteria

Submit source or a commit ID after Git has been introduced, the command and meaningful output, the changed behavior, and a note stating what you completed independently and where you used help. Never submit secrets or real student data.
