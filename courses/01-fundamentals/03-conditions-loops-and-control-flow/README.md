## Lesson

### Core idea

Conditions choose a path and loops repeat work with an explicit stopping condition. Business rules should be readable and testable.

### Practical artifact

Implement accepted/full/waitlisted decisions and loop through several booking attempts.

## Exit check

- The lab artifact runs or is complete enough to explain.
- The learner can explain the core idea using a concrete request or booking example.
