## Lesson

### Core idea

The server opens a database connection pool, executes parameterized SQL, checks errors, and maps rows into application values.

### Practical artifact

Connect the API to PostgreSQL and persist student registration.

## Exit check

- The lab artifact runs or is complete enough to explain.
- The learner can explain the core idea using a concrete request or booking example.
