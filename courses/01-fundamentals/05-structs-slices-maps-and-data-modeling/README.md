## Lesson

### Core idea

Structs group related fields, slices preserve ordered collections, and maps provide keyed lookup. Model business entities with stable identifiers.

### Practical artifact

Model sessions and students, then use slices and maps to find a session.

## Exit check

- The lab artifact runs or is complete enough to explain.
- The learner can explain the core idea using a concrete request or booking example.
