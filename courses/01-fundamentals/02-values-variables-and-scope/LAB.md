# Lab: Values, variables, types, and scope

**Starting point:** the referenced repository example or an empty personal exercise folder.
**Deliverable:** a saved exercise or commit, observed output, and a short explanation of one success and one failure. Use only synthetic data.

## Steps

1. Create title, capacity, booked, and isOpen variables.
2. Calculate remaining := capacity - booked and print a sentence.
3. Change booked with assignment, then rerun.
4. Create and repair a type mismatch and an out-of-scope variable. Save the compiler messages in your notes.

## Acceptance checks

- [ ] Capacity 12 and booked 5 prints remaining 7.
- [ ] Student explains why assigning a string to booked fails.
