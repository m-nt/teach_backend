# Quiz: Values, variables, types, and scope

Allow 8 minutes, then 2 minutes for correction. Each question is worth 2 points: 1 for the key idea and 1 for a correct explanation or example. At least 4/6 is the lesson target; remediate missed prerequisites.

1. How do := and = differ?

2. What is the type of capacity - booked if both are int?

3. Can a local variable declared inside an if block be used after the block?

<details>
<summary>Instructor answer key — open after submission</summary>

1. Declaration with inferred type versus assignment to an existing variable.

2. int.

3. No, unless a separate variable was declared in an enclosing scope.
