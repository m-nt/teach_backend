## Lesson

### Core idea

A Go program starts in package main at func main. Variables name typed values; types constrain what operations and assignments are valid.

### Practical artifact

Create a program that prints a class title, seat count, and whether booking is open.

## Exit check

- The lab artifact runs or is complete enough to explain.
- The learner can explain the core idea using a concrete request or booking example.
