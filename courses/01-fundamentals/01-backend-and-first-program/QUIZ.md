# Quiz: What a backend does; your first Go program

Allow 8 minutes, then 2 minutes for correction. Each question is worth 2 points: 1 for the key idea and 1 for a correct explanation or example. At least 4/6 is the lesson target; remediate missed prerequisites.

1. What is the difference between source code and output?

2. Where should the rule “do not overbook” be enforced?

3. Does changing a student name change their identity?

<details>
<summary>Instructor answer key — open after submission</summary>

1. Source is the instructions we edit; output is what executing them produces.

2. In the backend; later the database also helps enforce consistency.

3. No. A stable ID represents identity independently of the name.
