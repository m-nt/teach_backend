## Lesson

### Core idea

Relational tables represent entities and relationships. Primary keys identify rows, foreign keys preserve references, and constraints enforce selected business invariants.

### Practical artifact

Create student, session, and booking tables and query availability.

## Exit check

- The lab artifact runs or is complete enough to explain.
- The learner can explain the core idea using a concrete request or booking example.
