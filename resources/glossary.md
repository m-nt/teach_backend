# Working glossary

| Term | Plain-language meaning |
|---|---|
| Backend | Server-side program that checks rules and coordinates data and services |
| Frontend / client | The interface or program sending requests |
| Terminal | A text interface for running commands |
| Working directory | The folder a command currently operates in |
| IDE / editor | A tool for reading and changing source code |
| Compiler | A tool that translates and checks source code to produce executable code |
| Type / variable / scope | Kind of value / named value / where a name is usable |
| Function | A named operation with inputs and outputs |
| Error | A reported failure that the caller must handle |
| Module / package | A versioned Go dependency unit / a collection of Go source compiled together |
| Entity / ID | A business thing with continuing identity / its stable identifier |
| Course / session | A subject being taught / a specific scheduled offering |
| Invariant | A rule that must remain true, such as bookings never exceeding capacity |
| API / contract | A program interface / the agreed requests, responses, and behavior |
| HTTP / JSON | A request-response protocol / a data representation |
| Database / schema | Stored structured data / its tables, types, and constraints |
| Primary / foreign key | Row identifier / reference to another table’s row |
| Transaction | Related database operations committed or rolled back as a unit |
| Index | Extra database structure that can speed particular queries at a cost |
| Authentication / authorization | Identifying the caller / deciding the caller’s permissions |
| Hash / encryption | A one-way digest operation / reversible protection using a key |
| Session token | A secret proving possession of a server-recognized login session |
| OTP | A short-lived one-time verification secret |
| Image / container | Packaged runtime template / an instance of it |
| Port / volume | Network endpoint number / storage with an independent lifecycle |
| Cache / TTL | A derived copy for quicker reads / its allowed lifetime |
| Queue / outbox | Work awaiting processing / transactional record of delivery intent |
| Idempotency | Repeating one logical operation has the intended single effect |
| DNS / domain | Name-resolution system / a name within that system |
| TLS / certificate | Encrypted authenticated transport / evidence linking a public key to a name under a trust model |
| Pod / Deployment / Service | Kubernetes scheduling unit / replica controller / stable network discovery |
| Readiness / liveness | Able to receive traffic / process should remain running |
| SLI / SLO | Measured service indicator / target over a defined time window |
| RPO / RTO | Acceptable data loss / acceptable recovery duration |
